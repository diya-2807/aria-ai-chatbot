# Aria AI — Smart Coding & Idea Companion

A clean, responsive AI chat interface powered by an in-browser reasoning engine built with pure HTML, CSS, and vanilla JavaScript.

## Features
- **Zero API Key Required**: Runs 100% locally in the browser with an extensive pre-fed knowledge base.
- **Deep Technical Domains**: Modern JavaScript, CSS layout strategies, Node.js, algorithms, Big O, and project planning.
- **Markdown & Code Highlighting**: Formatted code blocks with a 1-click **Copy Code** button.
- **Interactive Follow-up Chips**: Contextual recommendation pills after every answer.
- **Local Persistence**: Saves chat sessions to `localStorage`.

## Running Locally
Open `index.html` in any browser. No build tools or backend servers required.
